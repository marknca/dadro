DADRO / User guide / 2 November 2026

Your machine.
A clear reference for every move.

Use DADRO to read a mill or lathe’s scales, establish a working zero, compare positions, and step through an XY hole circle. This guide covers the current Python/Qt application launched by src/app.py.

DADRO is a digital readout for a YADRO DRO:int4 controller. You move the machine yourself. Its diagrams and targets help you interpret position; they do not drive motors, detect a cut, or confirm that a hole has been drilled.

First time here?

Try the five-minute walkthrough, then choose and connect your machine.

At the machine?

Jump to zeros and ABS/REL, Remember point, or Lay out holes.

Something unexpected?

Check what survives a reconnect or use the troubleshooting table.

Use your browser’s Find command to search this guide. It works offline when kept with the repository’s docs/ folder. Your browser’s Print command produces a reading copy; worked examples accompany both interactive lessons.

01 · Quick start

For a first look, launch python3 -B src/app.py --demo from the repository or release directory. If dependencies are not installed, follow Install and launch first. No controller is needed.

Already have saved points? Starting the XYZ demo applies the default three-axis mill setup. If that differs from your current scale setup, ordinary points clear; if the machine profile differs, Origin clears too. The saved hardware configuration is retained, but points are not isolated in a separate demo workspace. Use this page’s lessons to practice without changing app data.

  1. Watch X, Y, and Z. The status bar identifies simulated data. All three axes travel between 0 and 30 mm at different speeds. New windows show inches.
  2. Select mm. The unit toggle changes all readouts. The demonstration’s physical travel stays the same.
  3. Try a relative zero. Set X to REL, then press its 0. X now shows travel since that instant. Switch X to ABS to return to its main coordinate.
  4. Save a reference. Open Remember point, click Remember this point, then select its card. A signed distance appears beneath each live reading. Choose Hide distances when finished.
  5. Explore a circle. Open Lay out holes, enter a positive diameter, and inspect the preview. Choose Start circle to see target guidance. The demo continues its own motion; it does not travel to the targets. Choose Finish circle to restore your X/Y modes and offsets.
  6. Stop. Disconnect stops the demonstration and leaves the last readings visible. Quit closes the app after acquisition stops.

Before using physical scales: verify the selected profile, channel mapping, input directions, units, and any lathe geometry against known travel. Establish the datum after connecting. A saved configuration or a saved Origin does not restore the machine’s physical reference after a scale reset.

For everyday work: connect → check the status and units → establish ABS zeros → use REL for incremental measurements → verify your reference again after any reconnect or mode-changing operation.

02 · Install and launch

You need Python 3, a working graphical desktop, PyQt6, and pyserial. Hardware use also needs a compatible DRO:int4 interface, fitted scales, and access to its serial port. The built-in demo needs no hardware.

From the repository or source release

The release/ directory is a movable source distribution. Copy the entire directory, keeping src/, assets/, and REQUIREMENTS.txt together. It does not include Python or installed dependencies. These commands work from either the repository root or that release directory:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r REQUIREMENTS.txt
python -B src/app.py

On Windows PowerShell, create the environment with py -3 -m venv .venv. You can use its interpreter directly without activating it:

.\.venv\Scripts\python.exe -m pip install -r REQUIREMENTS.txt
.\.venv\Scripts\python.exe -B src/app.py

The package is named pyserial, although Python imports it as serial. The unrelated package named serial is not a substitute.

Raspberry Pi OS

For the documented Bookworm-or-newer setup, use the distro packages and system Python in a graphical desktop session:

sudo apt update
sudo apt install python3-pyqt6 python3-serial qt6-wayland
/usr/bin/python3 -B src/app.py

Keep the Qt runtime and its plugins from the same installation. If you use a virtual environment instead, read the Pi installation and Qt troubleshooting notes before mixing it with system plugins.

03 · Choose and connect your machine

On first launch, choose the card that matches your fitted scales, then select Next: scales →. Selecting a card alone does not connect. Solid arrows identify measured travel; dashed arrows identify movement without a scale.

Choose by the movements you actually measure
Machine cardRequired scalesReadouts and use
Mill · Table travelX, YTwo table movements. XY hole-circle guidance is available.
Mill · Table + verticalX, Y, ZOne vertical scale, including an installation whose only vertical scale is on the quill.
Mill · Vertical + quillX, Y, Z, QSeparate main vertical and quill scales combine into one Z readout.
Lathe · Cross slide + carriageX, Z1Cross-slide radius or diameter plus carriage travel. Milling functions are hidden.
Lathe · With compoundX, Z1, Z2A separately measured compound slide contributes to X and longitudinal travel. Display Z1/Z2 separately or as summed Z.

A machine having a quill does not automatically require four scales. Choose Vertical + quill only when both vertical movements have separate scales.

Fine tune your setup

  1. Choose the Interface. Select a detected serial device or paste its full path/COM name. The field is editable. Paste paths containing /, because that key is reserved for leaving keyboard editing mode.
  2. Map each scale. Assign a distinct controller channel from 0–3 to each required movement. Follow the actual wiring; default order is only a starting point.
  3. Choose each input Direction. + keeps the scale’s incoming sign; − reverses it before coordinates are calculated. This is separate from the direction control beside the live readout.
  4. Set lathe geometry if shown. Choose X diameter or radius, compound angle where applicable, and separate or summed Z. See coordinate examples.
  5. Set Edge finding toolhead width. Enter the full width/diameter of the tool used for point offsets. The default is 0.200 in / 5.080 mm. Its own in/mm toggle is independent of readout units. The ½ badge previews the correction.
  6. Select Save & connect. The app saves valid settings first, opens the readout, and detects the scales. Watch the status bar for progress or an error.

Save & connect requires a nonempty interface, distinct channels, a valid compound angle (−180° to +180°), and a finite toolhead width greater than zero and no more than 1,000 mm. An explanation appears above the actions when a field is invalid. A missing controller does not prevent valid settings from being saved.

Change a saved setup

Use the top-right ⚙ Settings control. It opens the scale settings; ← Machine profile returns to the cards. Back/Next retains your draft. Cancel from either step discards the draft and preserves the active connection, datums, and any hole circle. First-run setup has no Cancel route to an unconfigured readout; the demo remains available.

Saving reconnects, even for a toolhead-only edit. It ends an active circle and clears software zeros. Changing scale settings also affects saved points; consult the persistence table before applying a change. A failed settings write keeps your draft visible and leaves the active setup in place.

Verify each physical motion after connecting: move one slide a known amount, check the matching axis and sign, and check combined inputs independently. Then establish your working datum. The app cannot infer correct wiring, mechanical angle, or calibration from successful scale detection.

05 · Establish zeros and measure in ABS/REL

ABS is your main software datum. REL subtracts an additional, independent offset from ABS. Neither is a hardware reset. Switching modes recalls an offset; it does not capture a new zero.

Set a main datum

Position at your reference, select ABS on the required axis, then press its 0. Repeat for the other axes. The app now measures from that reference.

Measure an increment

Select REL, press 0 at the start, and move. Read the signed travel. Return to ABS to see the main coordinate again.

Remove an offset

Choose the mode to clear, then Clear zero. In REL this returns to the ABS coordinate; in ABS it returns to the underlying machine coordinate.

Changing an ABS zero also shifts REL coordinates because REL is based on ABS; the stored REL offset remains. Clearing ABS does not secretly clear REL. To clear both, select and clear each mode. Clear zero affects all axes’ currently selected modes, so check mixed modes before using it.

Try the same position in different frames

This lesson represents one mill axis. It changes only this page and resets on reload. The position field always uses millimetres so you can distinguish physical motion from display-unit changes.

06 · Quill and lathe coordinates

Input directions in Settings are applied before machine geometry. The readout’s +/− control reverses the final coordinate after software offsets. Use input directions to make combined motions agree physically; use display direction to choose how you read an axis.

Mill with separate vertical and quill scales

Z = directed main vertical + directed quill. With main vertical +6 mm and quill +2 mm, combined Z is +8 mm. If the quill’s input direction is reversed, the same incoming readings yield +4 mm. If either vertical scale is unavailable, combined Z shows a dash; the app does not assume the missing contribution is zero.

Lathe radius versus diameter

In radius mode, X reports cross-slide travel after geometry and zeros. In diameter mode, X is doubled and labeled Ø X. A 1 mm radial move changes a diameter reading by 2 mm. Saved-point X distances and offset previews follow that display convention too.

Lathe with compound

The configured angle is measured from positive Z. At a positive angle, positive compound travel reduces radial X. Given directed scale values:

radial X = cross slide − sin(angle) × compound
Z2       = cos(angle) × compound
summed Z = carriage + Z2

For cross slide 10 mm, carriage 20 mm, compound 4 mm, and angle 30°, radial X is 8 mm, projected Z2 is approximately 3.464 mm, diameter X is 16 mm, and summed Z is approximately 23.464 mm, before software zeros. Separate mode shows X, Z1 (carriage), and projected Z2; summed mode shows X and combined Z.

A missing compound reading blanks dependent X and Z2 coordinates, and summed Z if selected. Independent coordinates can remain available. Verify the entered angle and sign against a known movement on the machine before relying on compensated coordinates.

07 · Remember points and keep an Origin

Use saved points when you want to return to a physical position or compare travel without changing the main readout’s zeros.

  1. Connect or start a demo, then open Remember point.
  2. Choose Remember this point. Its control becomes a numbered card, with the displayed coordinates recorded beneath the name. A fresh capture control appears below it.
  3. Select the point card. Each axis gains a Point n · Δ overlay showing current position − saved position.
  4. Move and compare the signed distances. For a point at X = 10 mm, X = 15 mm gives +5 mm; X = 8 mm gives −2 mm in positive direction.
  5. Select the same card again or choose Hide distances to remove the overlays. Closing the drawer retains the selection and distances.

Capture requires a ready live connection and finite readings for every displayed axis. Two-axis profiles require only their two displayed axes. Selecting, inspecting, offsetting, and deleting existing points also works while disconnected, but live distance overlays show dashes until valid readings resume. Capturing a point does not automatically select it.

Cards keep the coordinate snapshot from capture (or the latest offset application). Changing ABS/REL or zero moves the large coordinate, but leaves the saved physical reference and its distance intact. Switching units converts the card; reversing direction changes the live distance’s sign. Each axis’s distance is independent, not a combined 3D length.

Name one point Origin

  1. Choose Set Origin beside a saved point’s name. It becomes Origin and locks automatically.
  2. To replace it, choose the closed lock to Unlock Origin. Other Set Origin controls become available.
  3. Choose Set Origin on the new reference. The former Origin remains as a numbered point with a temporary Was origin highlight; the new Origin is locked.

Origin is a saved reference, not an axis zero. Designating or transferring it does not change any coordinates or datums. Its lock prevents another point from replacing it; it does not prevent explicit deletion or protect it from a machine-profile change.

Use a card’s trash control to delete it. Deleting the selected card hides its distances. Other cards keep their numbers; new captures reuse the lowest available number, so list order may differ from numerical order. There is no undo control for point deletion.

Explore saved points in 3D

Choose Visualizer in the drawer. Click a marker or card to select its point. Drag to rotate, scroll to zoom, and use Reset view to fit the points. For keyboard rotation, enter the plot with Enter first; arrows rotate, +/− zoom, and Home resets. Press / to return to navigation.

The view uses equal scale on all displayed axes. Two-axis setups form a plane. Zero/ABS/REL changes do not move the markers; direction changes mirror them. Lathe diameter scaling is reflected in the plot, so it is a view of measured coordinates rather than a model of the workpiece. Coincident points can be selected individually through their cards. Above 40 points, only the selected point’s number is labeled.

Close the visualizer to see live distance overlays again. Points persist across ordinary reconnects and relaunches; a new launch starts with none selected. Scale-setting and profile changes have different clearing rules, described in Saving and restarting.

08 · Apply a toolhead offset to a point

If a captured position represents tool contact, you can shift the saved reference by half the configured toolhead width. DADRO applies the correction you choose; it does not detect contact or choose the side of an edge for you.

  1. Check Settings → Edge finding toolhead. Width is the full toolhead width/diameter; the ½ preview is the physical correction. The default 0.200 in toolhead gives 0.100 in (2.540 mm).
  2. On a saved point, choose Offset. Its editor opens inside the card.
  3. Choose the axis and + or −. The sign follows the current displayed axis direction. Check which side of the reference you intend to represent.
  4. Choose Apply offset. The saved position, distance overlay, and marker update; a chip records the correction.

Applying again replaces the correction from the original capture; offsets do not stack. Cancel leaves the point unchanged. Remove offset restores the original physical position and original coordinate snapshot.

For example, a positive-direction mill point captured at X = 10 mm becomes X = 12.540 mm after a positive offset using the default toolhead. Applying it again still yields 12.540 mm. Removing it returns to 10 mm. In lathe diameter mode the same 2.540 mm radial correction changes the displayed X by 5.080 mm.

Each point retains the width used when its correction was applied. Editing the toolhead setting does not resize existing corrections; Apply again explicitly uses the new width. Applying also refreshes the card’s coordinate snapshot using the current datums and directions. Axis zeros remain unchanged, and no scale commands are sent.

The former standalone Edge Finder workflow is not available in the current app. Point offsets are the current way to apply the configured toolhead correction.

09 · Lay out a circle of holes

Lay out holes is available for mill profiles. It guides manual XY positioning using the historical HCXY angle convention. Z is optional for starting a circle.

  1. Establish X/Y datums and directions first. The circle’s center is interpreted in each axis’s selected coordinate frame when you start.
  2. Open Lay out holes or press F3. The visualizer opens over the readouts.
  3. Enter Center X, Center Y, Circle diameter, Number of holes, and Starting angle. Lengths use current readout units. On first opening, available X/Y readings seed the center and the count starts at four.
  4. Select Start circle. The visualizer closes, X/Y temporarily use REL guidance, and the drawer changes to Hole targets.
  5. Move until both main X/Y readouts are zero. The drawer’s large X/Y values are the target coordinates in your original frame; the main readings show your displacement from that target. If a main reading is positive, you are past the target in that axis’s positive direction.
  6. Choose another hole. Use Previous/Next or enter a hole number and press Enter. Navigation does not wrap. Changing the target does not move the machine.
  7. Finish explicitly. Choose Finish circle at any hole to restore the prior X/Y modes and offsets. Selecting the last hole does not finish automatically.

Cancel circle, closing the hole drawer, or Escape in that panel cancels and restores X/Y. Disconnecting, reconnecting, applying Settings, or a serial error also ends the circle. Opening Settings then Cancel preserves it. Browsing Remember point does not end an active circle, although opening Lay out holes clears the selected point-distance overlay.

Target selected does not mean hole drilled. You can skip or revisit any hole without first reaching zero. The visualizer counts visited targets, including the current one; it cannot detect drilling. Reopen it with Visualizer, then close just the visualizer to resume reading scales without ending the circle.

Understand the angle before you cut

0° starts on −Y. 90° starts on −X. With +X to the right and +Y upward, increasing angles go clockwise. For zero-based hole index i:

θ = starting angle + i × 360° / number of holes
target X = center X − (diameter / 2) × sin(θ)
target Y = center Y − (diameter / 2) × cos(θ)
main readout = current coordinate − target coordinate
Explore the angle and target coordinates

Practice only, in millimetres. This lesson supports 1–64 holes and does not connect to DADRO. Choose a target to see its exact coordinates.

Limits and controls during a circle

The app accepts a whole-number count from 1 to 10,000, positive diameter up to 10,000,000 mm, center magnitudes up to 10,000,000 mm, and starting angle from −360° to +360°. These software limits are not a statement of machine travel. Numeric fields accept numbers, not DOS-style expressions. Subsequent openings retain entered geometry within the same window.

X/Y sign, zero, ABS/REL, and Clear zero lock during stepping. Z remains usable, and changing display units converts the presentation without moving the targets. Start needs finite X/Y readings; retained disconnected readings can be used for inspection, but they provide no live positioning. A reconnect ends that sequence and clears software zeros.

The double-ring marker identifies the current target, filled visited markers identify previously selected targets, and open markers are unvisited. Dense patterns draw up to 361 representative markers; target coordinates and the visited counter remain exact. Only circles of up to 24 holes label every marker.

10 · Read the tool path

The Tool path panel below the main actions shows a sampled trail of the configured coordinates. Start marks the first retained position or a new segment after a gap. Tool marks the latest accepted position.

It checks every 2 seconds and accepts a new point after at least 0.001 in / 0.0254 mm of straight-line travel from the last accepted physical coordinate. Smaller steps accumulate; tiny stationary jitter may not draw a new segment. The main readouts continue updating independently.

Missing coordinates and connection interruptions create gaps. A straight line between samples does not reconstruct the actual motion between checks.

Disconnect retains the trail; starting acquisition, applying setup, or sending Fast-mode pulses clears it. Quitting discards it. This is a visual aid, not a complete motion log or an exportable machining record. Explore how movement and noise affect the path.

11 · Connection status and Fast mode

Connection progresses through passive mode, controller version checking, detection of each configured channel, initial readings, and live updates. These operations happen away from the interface thread. Use Cancel during connection or Disconnect afterward; allow Stopping… to complete before starting again.

The controller normally sends changed readings. A stationary scale may retain its last reading without sending a new sample; that alone is not a disconnection. A missing scale is different: dependent readouts show dashes and the status identifies the problem. On an ordinary disconnect, last displayed values remain visible. Always read the connection status before treating them as live.

When Enable Fast mode appears

  1. Keep the machine still and read the slow-reading banner. Fast mode is an explicit hardware action; it is never automatically enabled at startup.
  2. Choose Enable Fast mode. Live readings pause while the app measures all detected inputs.
  3. Already-fast inputs are skipped. Where needed, the app sends scale-mode pulses and checks the resulting cadence. Progress stays visible.
  4. Wait for live readings to resume, then verify the reference and re-establish the datum if pulses were sent.

Mode-changing pulses can alter the scale reference. Software zeros clear before pulses are sent, and the path is reset. Cancel or Disconnect stops subsequent commands but cannot undo a pulse already sent. If setup is interrupted, follow the app’s instruction to restore scales to normal before reconnecting, then verify the physical reference before reusing saved points.

Settings and coordinate-changing operations are disabled during the hardware sequence; status text explains the work in progress. A Fast-mode attempt ends any active hole circle. Only one attempt is made per connection. If readings remain slow, the banner directs you to check the scales and connection.

The Fast mode indicator describes measured input cadence, not a guarantee of overall latency or accuracy. Idle inputs retain their last classification. It is absent in the built-in XYZ demo. Hover the indicator/status for channel measurements. Higher scale cadence cannot remove shared serial-bandwidth limits, USB buffering, or mechanical error.

13 · Practice without hardware

Automatic XYZ demo

Use --demo or Try XYZ demo on the machine-selection screen. All axes start at zero and reverse at 30 mm and 0 mm. X moves at 1 mm/s, Y at 0.6 mm/s, and Z at 0.25 mm/s. They do not simulate acceleration or sensor noise.

The demo does not replace the saved hardware configuration. It does apply a default Mill · Table + vertical setup to the active window, so saved-point clearing rules still apply: an incompatible scale setup clears ordinary points, and a different profile also clears Origin. Returning to hardware does not recover cleared points.

Disconnect stops the demo; choosing it again restarts its travel from zero. To return to hardware, open Settings and apply the intended profile and interface. If you already have a saved configuration, Settings/Connect opens it for review and application; a fresh unconfigured demo first requires setup.

Manual mill or lathe simulator

Use the full repository’s separate simulator when you need exact, stationary positions. It uses the same dependencies. Start both programs on the same computer in separate terminals:

# Terminal 1
python3 -B src/machine_simulator.py

# Terminal 2
python3 -B src/app.py --port socket://127.0.0.1:8765

In the simulator, choose the machine and use Copy address. Paste it into DADRO’s Interface field and apply a matching configuration:

SimulatorDADRO cardChannels, input direction +
Three-axis millMill · Table + verticalX = 0, Y = 1, Z = 2
Two-axis latheLathe · Cross slide + carriageX = 0, Z1 = 1

Drag sliders or type positions and press Return. Each position stays until changed. Sliders cover −500 to +500 mm. Changing the simulator’s machine disconnects DADRO and resets simulated positions. Update DADRO’s profile and reconnect. DADRO saves an applied simulator interface, so choose your hardware port again when returning to real scales.

A repeatable practice sequence

  1. Choose the mill, positive directions, ABS with no zeros, and mm units. Set simulator X = 25.40, Y = −10.00, Z = 12.50. Read 25.400, −10.000, 12.500.
  2. Switch to inches. Read 1.0000, −0.3937, 0.4921. Switch back to mm.
  3. Zero X in DADRO; set simulator X = 26.40. Read 1.000 mm. Reverse X and read −1.000 mm. Restore positive direction.
  4. Capture a point, select it, and move X by 5 mm. Check a +5 mm point distance even if you change the main X zero.
  5. Clear the appropriate X/Y offsets. Use the four-hole example above and manually set each simulator target; both main readings should reach zero.

The simulator checks software workflows and the protocol path; it does not reproduce real electrical signaling, scale noise, calibration, or serial latency. See the manual simulator guide for port conflicts, exact controls, and dependency repair.

14 · What is saved, and what resets?

Configuration and remembered points live in the current user’s Qt settings store, outside the source/release folder. Copying the program does not transfer another user’s setup. DADRO has no in-app settings or point export/import workflow.

Use this table before changing a setup or reconnecting
Item or actionWhat to expect
Saved machine setupProfile, interface, channel mapping, input directions, lathe geometry/display choices, toolhead width, and toolhead units return on next launch. Saving can succeed even if hardware is unplugged.
Readout precisionSaved immediately for each axis and separately for mm/in. X and Ø X share the X preference.
Readout units, sign, modeA simple reconnect keeps the current selections. Applying a machine configuration (including starting the XYZ demo) resets display directions to + and modes to ABS while keeping the current units. A new window starts in inches, positive directions, and ABS.
ABS and REL zerosNot restored on launch. Both clear whenever acquisition starts again or setup is applied. Fast-mode pulses clear them too.
Ordinary disconnect or serial errorSaved points remain. The last display/trail may remain visible, but it is not live. An active circle ends. Reconnect clears zeros and starts a new trail.
Saved points, offsets, Origin lockPersist through ordinary reconnects and quitting with the same setup. New launches select no distance reference. The temporary Was origin highlight is not saved.
Save unchanged setup or toolhead-only editsKeep points. Saving still reconnects and clears software zeros. Existing point offsets keep their original size.
Change scale settings within a profileChanges to interface, channels, input directions, angle, diameter mode, or summed-Z mode clear ordinary points. Origin remains with its original setup; distances, offsets, and its marker are unavailable until that setup is restored.
Apply a different machine profileClear every point, including locked Origin. This includes switching between two mill profiles. Returning to the old profile does not restore deleted points.
Start XYZ demoApply a default three-axis mill setup without replacing the saved hardware configuration. The same point-clearing rules apply if its setup/profile differs. The demo is not a separate saved-point workspace.
Cancel SettingsDiscard only the draft. Preserve the active configuration, connection, zeros, points, selection, and circle.
Hole-circle geometry and progressEntered geometry lasts in the current window. Sequence progress clears on finish/cancel or acquisition changes; it is not a saved job.
Tool path and camera choicesSession-only. Quit discards the trail. Acquisition starts, applied setup, and Fast-mode pulses clear it.

Persistence is not physical verification. Points retain scale-based coordinates. If the controller or scales reset their physical reference, old points may no longer refer to the same machine locations even though their cards are still saved. Check against a known reference before using them.

If a point write fails, the drawer reports it and keeps your changes in the current window; they may not survive quitting. Invalid stored point data is left untouched on load. A settings-write failure keeps configuration edits in the draft and does not reconnect. A precision-write failure keeps the choice for the current session and reports it in the status bar.

15 · Troubleshooting

Start with the status bar and its hover detail. Check whether you are seeing live hardware, simulated data, or retained disconnected values. A problem report is most useful when it includes the profile, mapped channels, interface, exact message, units, and whether the same behavior occurs in the demo.

SymptomCheck and next action
Cannot open the serial portVerify the selected interface using the port-list command, reconnect the adapter, and close any other program using it. Check OS access permissions. Correct the interface in Settings and reconnect.
No supported scales detectedVerify the controller connection and baud, scale power/wiring, and mapped channels 0–3. A successful interface open alone does not confirm scale detection.
One or more axes show —Read the missing-scale message and compare channel assignments to wiring. Combined Z requires both vertical inputs; compound-derived coordinates require the compound input. Missing input is never treated as zero.
Value is twice the expected X movementCheck lathe diameter mode. Ø X intentionally doubles radial travel, including saved-point distances and corrections.
Wrong sign or unexpected combined travelCheck input directions in Settings, then displayed +/−, compound angle, and summed-Z choice. Test one physical motion at a time. Saving corrected setup reconnects and clears zeros.
Unexpected zero or distanceCheck units, each axis’s ABS/REL selection, and active hole guidance. Distinguish the large coordinate from a saved point’s Δ overlay. Clear zero removes an offset; Origin designation does not zero an axis.
Numbers stop changingCheck connection state first. Stationary scales may send no changed records. A disconnected screen retains its last sample; the automatic demo stops on Disconnect. Move a known safe amount and inspect the status.
Zero or Settings is disabledDuring a circle, X/Y reference controls lock. During Fast-mode setup, readings pause and Settings is disabled. Read the activity message and finish/cancel the relevant operation.
Main buttons disappearedClose the open Visualizer using its × or drawer toggle. The overlay hides the action column; it does not stop acquisition.
Remember this point is unavailableCapture requires a ready connection and valid readings for every displayed axis. Existing points remain available for browsing while disconnected.
Origin shows coordinates but no distancesThe scale setup differs from the one attached to that Origin. Restore the original setup to use its reference again. Applying a different profile clears it entirely.
Circle targets differ from expectationsCheck current units, original X/Y modes/directions, and the 0° = −Y, 90° = −X convention. Target cards show coordinates; main readouts show displacement from them.
Tool path seems still or incompleteIt samples every 2 seconds and needs 0.0254 mm of accumulated travel. Gaps indicate unavailable data. It does not show every motion or replace the live readouts.
Last digit flickersReducing decimal places changes presentation only. DADRO does not smooth the main readings. Compare stationary behavior and a slow known move; larger jumps, resets, or sustained drift need investigation of the scales and connection.
Fast-mode setup was interruptedRestore scale modes as directed before reconnecting. An already-sent pulse cannot be undone by Cancel. Re-establish the datum and verify remembered references.
Settings or point save errorRead the exact message and check the current user’s settings-store access. Do not assume in-memory point changes survived quitting. Configuration save failures leave the draft open.

Installation and desktop problems

Python reports a missing PyQt6 or serial module

Use the interpreter/environment where you installed the dependencies. From the repository or release directory run python -m pip install -r REQUIREMENTS.txt in the intended virtual environment. On the documented Pi setup, use the distro packages and /usr/bin/python3.

“serial” has no attribute “Serial” or “serial_for_url”

The wrong or incomplete Python module may be loaded. Inspect it using the same interpreter that runs DADRO:

python3 -c "import sys, serial; print(sys.executable); print(serial.__file__); print(callable(getattr(serial, 'Serial', None))); print(callable(getattr(serial, 'serial_for_url', None)))"
python3 -m pip show pyserial serial

If the unrelated serial distribution is installed, remove it before reinstalling pyserial. If a local serial.py or serial/ shadows the package, rename that conflicting module. For a damaged virtual-environment install, use python3 -m pip install --force-reinstall pyserial. For distro-managed Pi Python, use sudo apt install --reinstall python3-serial. Quit and relaunch DADRO after repair; reconnecting alone retains the imported module.

A Wayland or Qt theme warning appears on Raspberry Pi

If the window opens and works, the warning alone does not establish a failed launch. If the window fails to open, capture the complete terminal output and confirm you are in a graphical desktop session. Follow the Qt plugin diagnosis; do not copy arbitrary plugins between system and pip installations.

The manual simulator is waiting for DADRO

Run both apps on the same computer, copy the simulator’s current socket address, and paste it into DADRO’s Interface field. Match the profile and channels, then connect. If the default local port is occupied, stop the simulator server, choose a free port (or Automatic), restart it, and copy the new address. An applied socket address stays saved until changed.

16 · Reference and glossary

Datum
A reference from which coordinates are measured. DADRO’s ABS datum is a software offset; it is not an absolute encoder guarantee.
REL
An extra offset from ABS, useful for measuring one move without losing the main reference.
Origin
One designated remembered point. It has a replacement lock and special same-profile retention rules; it is separate from every axis’s zero.
Δ (delta)
The signed distance from a selected saved point along an axis, in current display direction and units.
Input direction / display direction
Input direction changes a scale’s contribution before geometry. Display direction reverses the resulting axis after offsets.
Q, Z1, Z2
Q is the separately measured quill input. On a lathe, Z1 is carriage travel; Z2 is the compound’s projected longitudinal contribution.
Ø X
Lathe diameter display: twice the radial X coordinate after offsets.
Target / visited
A target is the selected hole location. Visited means selected at least once during this circle; it does not mean machined.
Resolution / precision / accuracy
Scale resolution limits the smallest reported increment. Display precision chooses decimal places. Physical accuracy depends on the installed and verified measurement system.
