The supplied DRO:ddisp 0.5a is a programmable readout engine. Its machining commands come from the selected .CFG profile and included macros. This reference combines those actual definitions with command tables and control flow recovered from DDISP.EXE.

Scope: the files in original-bootable-floppy/yadro-bootable-dos-6.22/. “Recovered” means visible in supplied source or traced in the executable; it does not mean tested in DOS or on a machine. This work did not run the DOS programs or send commands to scales. MS-DOS system utilities such as SYS.COM and TREE.COM are outside the YADRO command catalog.

Launch commands and bundled utilities

The disk boots to a DOS prompt: AUTOEXEC.BAT sets the prompt and path, but does not launch YADRO. Run the mill or lathe launcher from its directory. Both directories contain the same DDISP executable; their generated wiring and scaling includes differ.

F10 is the terminal utility’s exit key. It is not DDISP’s exit key and is not bound by any of these five profiles. Function-key bindings belong to configuration files; the website’s example F10 macro is not a binding in the supplied files.

Every public machining and tool command

DADRO now implements MILL3’s HCXY workflow through Hole circle / F3. See the setup guide and interactive circle explorer for its angle convention and coordinate behavior.

Edge Finder is no longer included in DADRO. The EFN and EFs entries below document the original DOS edge-finding macros for historical reference; they are not available in the current app.

Filter by the profile you plan to run. Each row preserves the exact original menu name, describes the action, and includes its source and body. The short prefix at the start of a name is what you normally type. The tools include #00 through #10—eleven numbered entries, despite the old website saying ten.

Reading the zero commands: ZX, ZA, and their relatives change software offsets. In absolute mode they alter a shadow offset; in relative mode they alter the relative offset. Hardware zeroing is a separate startup prompt. “Absolute” therefore refers to the program’s established datum, not necessarily the unchanged physical scale reading.

HCXY Hole circle X F3

Ask for X/Y center, number of holes, circle diameter, and starting angle. Step through evenly spaced hole positions, showing zero at each target. Save and restore X/Y offsets and absolute/relative modes. The original title says “X”, but the macro uses both X and Y.

Original macro body
Macro:HCXY Hole circle X
  fvar HCHoles, HCAngle, HCDiam;
  fvar HCCenterX, HCCenterY;             // center of hole circle
  fvar HCOldOffsX, HCOldOffsY;           // remeber old Offsets
  fvar HCTX, HCTY;                           // temporary center
  fvar HCIncrement, HCIAngle, HCSteps;

  if (HCCenterX == 0) { HCCenterX = Disp1 }
  if (HCCenterY == 0) { HCCenterY = Disp2 }
  if (HCHoles == 0) { HCHoles = 4; }

  if (input("Hole Circle",
            "Center X (Disp1):", HCCenterX,
            "Center Y (Disp2):", HCCenterY,
            "Number of holes:", HCHoles,
            "Diameter:", HCDiam,
            "Starting angle:", HCAngle)) {

    HCOldOffsX = OffsetX;
    HCOldOffsY = OffsetY;
    execmacro("internalStatusAbsSave");
    execmacro("internalStatusRelX");
    execmacro("internalStatusRelY");

    HCIncrement = 360 / HCHoles;
    HCIAngle = HCAngle;
    HCSteps = HCHoles;
    HCTX = - HCCenterX + OffsetX;
    HCTY = - HCCenterY + OffsetY;
    while (HCSteps > 0) {
      OffsetX = (HCTX + sin(HCIAngle) * HCDiam / 2) / UnitScaling;
      OffsetY = (HCTY + cos(HCIAngle) * HCDiam / 2) / UnitScaling;

      if (!getnext("Move to X/Y = 0.0")) { break; }

      HCIAngle = HCIAngle + HCIncrement;
      HCSteps = HCSteps - 1;
    }

    OffsetX = HCOldOffsX;
    OffsetY = HCOldOffsY;

    execmacro("internalStatusAbsRestore");
  }
:EndM:BindKey:F3

The built-in YPL language

The executable has a sorted table of exactly 30 keywords at file offsets 0x18A4C–0x18AFF. The lexer searches 30 six-byte records at 0x4429–0x4465. This is stronger evidence than a string search: other math names embedded in the C runtime are not automatically YPL functions. The table has no fclose, fread, for, abs, or sinc entry.

YPL supports numeric variables, assignment, arithmetic + - * /, parentheses, comparisons, and C-style blocks. Macro execution uses exact names. The actual precreated readout variables are Dev0…Dev3, Disp1…Disp4, and DispSec1…DispSec4. For the default mill, Disp1 is X. The website’s Disp0/SecDisp0 naming is inconsistent with this binary.

Findings that affect using the commands

  1. The lathe QUICKTST copy is incomplete. It is exactly the first 24,576 bytes of the mill’s 50,770-byte file, while its MZ header still declares 50,770 bytes. The complete utility is in YADROM. No original files were repaired or changed.
  2. The lathe tool-edit dialogs contain an apparent typo. #E in L_TOOLS.INC:46 and TGC in LATHEXZ1.CFG:465/LATHE3.CFG:750 pass TTZ for tip radius, but declare and persist TTR. No TTZ declaration was found in the supplied CFG/INC files. These commands are present, but the dialog likely raises an unknown-variable error in the original interpreter.
  3. ARV does not use the requested center in its target equations. In LATHE3.CFG:600–665, the dialog collects ACVCenterX/ACVCenterZ, but lines 647–648 calculate offsets without those variables. Its intended purpose is concave-radius stepping; its geometry is not established as correct.
  4. CLH does not honor cancellation at every step. Its initial positioning and two base-circle getnext calls ignore the return value. The facet calls test it and break. Thus the generic “Esc aborts the whole cycle” description has exceptions in this source.
  5. Tool correction prevents changing units while active. The pre-display handler detects the changed unit, shows a message, and switches it back. Use #- to fully deactivate the tool before changing units and reselecting it. TGC- removes the correction handler but does not clear the tool selection or all stored geometry; #- additionally clears geometry, the active flag, and the displayed tool name.
  6. Extra profiles need matching generated includes. The default mill’s includes provide three devices; the default lathe’s provide two. The quill and three-axis-lathe profiles depend on additional mappings/scaling. Run the appropriate original setup for the actual hardware before treating an alternate profile as configured.
  7. Documentation describes other revisions too. This disk has 11 numbered tools, one-based Disp1 and DispSec1 names, software-zero public macros, and only three assigned function keys. The binary and shipped macro definitions take precedence over conflicting examples on the archived website.
